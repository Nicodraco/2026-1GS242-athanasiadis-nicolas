  ¿Cómo puedes hacerlo tú solo?

  Si quieres encenderlo tú mismo en el futuro (o si reinicias tu PC), sigue estos pasos:

   1. Asegúrate de tener MongoDB corriendo. (En tu caso parece que ya lo tienes instalado localmente en el puerto
      27017).
   2. Abre dos terminales en la carpeta raíz del proyecto (Proyecto-Pokemon).
   3. En la Terminal 1 (API):
   1     bun run dev:api
   4. En la Terminal 2 (Web):
   1     bun run dev:web
   5. Entra en tu navegador a: http://localhost:3000

  Nota: Si es la primera vez que lo corres y no hay Pokémon, usa este comando en una terminal aparte para cargar los
  datos:
   1 bun run --filter api import:pokeapi --limit 300
