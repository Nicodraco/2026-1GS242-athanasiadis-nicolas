## Proyectos destacados

### 1. DAMAS - Juego de Damas con IA A*
**Ruta:** `Proyectos/Proyecto 2 - Damas/`

- Arquitectura de microservicios (auth, game, ai, marketplace, ranking).
- IA implementada con algoritmo **A\*** para jugadas automáticas.
- Frontend moderno con React + TypeScript.
- Integración de pagos con Stripe y ranking de partidas.
- Docker Compose para ejecutar el stack completo.

Más detalle: `Proyectos/Proyecto 2 - Damas/README.md`

### 2. Pokemon Battle Rooms
**Ruta:** `Proyectos/Proyecto-Pokemon/`

- Batallas 1v1 por salas con código compartido.
- Backend con Bun + Hono y frontend con TanStack Start.
- Importación de catálogo desde PokeAPI.
- Flujo de login (Clerk) y tienda de shinys con Stripe.
- Soporte de entorno local y Docker.

Más detalle: `Proyectos/Proyecto-Pokemon/README.md`
